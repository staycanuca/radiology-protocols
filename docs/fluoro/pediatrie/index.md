# Protocoale Fluoroscopie Pediatrică

Protocoale clinice și tehnice de radioscopie pediatrică optimizate conform principiului ALARA (regim pulsat cu rată redusă de cadre, colimare strictă, îndepărtarea grilei antidifuzoare la sugari) pentru evaluarea anomaliilor renourinare și tratamentul dezinvaginării intestinale.
