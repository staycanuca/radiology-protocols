# Ghidul Protocoalelor de Fluoroscopie & C-Arm

Protocoale clinice și tehnice de fluoroscopie convențională (examinări dinamice cu substanță de contrast baritată și iodată) și proceduri ghidate prin arc în C mobil (**C-Arm**) intraoperator și intervențional, adaptate principiilor de radioprotecție **ALARA** și recomandărilor internaționale.
