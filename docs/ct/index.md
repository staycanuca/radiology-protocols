# Ghidul Protocoalelor de Tomografie Computerizată (CT)

Protocoale tehnice avansate de tomografie computerizată (native, angio-CT și multifazice cu substanță de contrast) pentru toate segmentele anatomice, optimizate conform principiului **ALARA** (modulare automată a dozei AEC, protocoale Ultra-Low Dose și reconstrucții iterative IR).
